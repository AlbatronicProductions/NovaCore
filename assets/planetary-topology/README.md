# Spherical terrain proof topology

**FIXTURE / DEVELOPMENT PROOF — not the normal production Earth library.**

`manifest.json` describes the small spherical-billboard proof library generated by
`PlanetarySphericalBillboardTopologyGenerator`. The optional
`NOVACORE_P2S2_ARTIFACT_OUTPUT` topology-test path reproduces its artifacts.

`PlanetarySphericalBillboardGpuProofLibrary`, the GPU/natural-terrain proofs and
`PlanetarySphericalBillboardGpuRuntimeTests` consume it. It protects manifold and
outward winding, adjacency, density distribution, physical-height/normal parity,
GPU lifecycle and indirect rendering. The supported **Development — Spherical
Terrain GPU Proof** launcher route remains reachable.

Normal Earth/Solar/Florida startup uses
[`../planetary-nested-scale-mesh`](../planetary-nested-scale-mesh/README.md).
These compact proof fixtures have a distinct consumer and are not duplicate
production assets. No format, artifact identity or runtime path changes here.
