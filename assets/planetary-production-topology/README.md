# Transactional terrain regression topology

**FIXTURE — retained current regression input, not the production Earth library.**

The 18 `.nctop2` levels and `production-manifest.json` are generated by
`PlanetaryProductionSphericalBillboardTopologyGenerator` and read by
`PlanetaryProductionSphericalBillboardTopologyLibrary` in `NovaCore.Graphics`.
The optional `NOVACORE_P2S5B_ARTIFACT_OUTPUT` topology-test path reproduces them.

Current consumers are `PlanetaryProductionSphericalBillboardTopologyTests`,
`PlanetaryProductionSphericalBillboardRuntimeTests` and
`FloridaFoundationSeatingTests`: deterministic topology/serialization,
transactional preparation/publication, culling and seating invariants shared with
the current renderer. Public format/API contract retirement is a separate decision.

Normal Earth/Solar/Florida startup loads the NCSM1 library in
[`../planetary-nested-scale-mesh`](../planetary-nested-scale-mesh/README.md).
The word “production” in this directory's historical name does not select a second
Earth renderer. Paths are retained to avoid changing fixture/hash/provenance and
public-loader contracts for a naming improvement.
