# Landing-page media

## M16.0 construction

`novacore-m16-construction.jpg` is an unchanged copy of the real application
capture `../engineering-evidence/scalable-launch-support/direct-ui/final-filled.png`.
The original uses a .png filename but contains JPEG data. The public image has
the matching .jpg extension; no resizing, retouching or generated content was used.

- Capture record: September 26, 2026, 3440 × 1440.
- Source: the normal unified NovaCore application, with the 21-part stock
  two-long-tank craft and two eight-member RCS rings.
- SHA-256: `077e9ca22c80eb88a5b6faecb6f51a19acab6d0e10950c0041c324aa67127b88`.
- Provenance: [capture record](../engineering-evidence/scalable-launch-support/direct-ui.json)
  and [scope notes](../engineering-evidence/scalable-launch-support/direct-ui/README.md).

The image is part of the banked M16.0 repository, but was captured during
development before the final bank. Its caption states that date and scope.
It illustrates construction, not terrain return, an orbital mission or public
release acceptance. The larger pictured craft is not the README's first-craft recipe.

The older M11 gallery and other historical images remain preserved, but are no
longer shown on the landing page. Nighttime flight and pad captures were omitted
from the final page because they add little visual clarity.
