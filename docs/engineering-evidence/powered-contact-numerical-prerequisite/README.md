## Why the failure is credible

The reference uses actual retained contact offsets/depths, not idealized geometry. Its seven-row pivoted linear solve has residual 5.52e-17 in the failed case. Positive normal and strictly interior friction conditions hold. A second independent affine block iteration reproduces the candidate's first/eighth sweeps within 9.02e-17. Source review confirms normal self-kick cancellation, speculative/recovery bias, tangent block, twist limit and update order. Thus the recorded error is against the converged local compliant response, not a mistaken comparison against an unclipped or differently ordered equation.

The independent solution algorithms share the K/Jacobian assembly and endpoint-velocity reconstruction with the candidate; reviewers checked those shared equations directly. They are not a full independent geometry or trajectory oracle. This implementation limit is explicitly corrected in primitive-limitations.md.

For the powered case, normal reaction error falls from 0.12349682954612629 N s at sweep one to 0.002512790148672339 at sweep eight, but remains 25.13 times the declared bar. The cold-cache control is worse at 0.0041628157499777885 N s. Neither a cache reset nor more iterations was adopted. This demonstrates a local finite-iteration accuracy failure for C from this real support cache. It does **not** prove long-run instability, a BEPU defect, a mass-only failure or impossibility of every bounded adapter.
