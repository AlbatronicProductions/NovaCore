## Preconditioner contract

See the preregistered [derivation](contract.md). With actual normal Jacobians J, inverse generalized mass W, K=J W J^T, and alpha=1/[omega*h*(omega*h+2)], define u=(1,...,1) and

`beta = -h*(u^T J delta_acceleration)/(u^T K u + alpha*sum(Kii))`.

Only beta*u is added. This is one scalar virtual-work projection with aggregate Jacobian response; no normal or full-system solve, trial sweeps, oracle, tuned weights or four-contact constant. It handles1..4 rows with unequal lever arms and nonparallel normals. It does not predict the complete differential torque response. The existing eight sweeps retain that responsibility and their original accuracy bars.

Previous/new gravity, force and torque are compared at the **same current-piece** inverse mass/inertia and duration. Unchanged mass-only gravity support is left to the existing changed-matrix solver; no old-mass preconditioning is introduced. This does not qualify a cache transition between different durations or geometries.

The common shift is stored separately as a signed mantissa/exponent; original normal differences remain in the immutable cache, and tangent/twist values remain unchanged. Materialized ordinary normal differences pass a1e-14 rounding check. Exact tiny h uses banked scaled arithmetic, not float dt. Negative represented guesses are rejected before projection; invalid/overflowing input fails without mutation. The domain includes the ordinary16,667-tick maximum.
