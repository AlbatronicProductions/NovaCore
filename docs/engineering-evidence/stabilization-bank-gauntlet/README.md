## Bounded corrections

Independent construction review proved two frontend ownership defects:

1. Moving an existing RCS group used the new-placement symmetry selector during
   socket enumeration, while commit used existing membership. `EditorSocketTargets`
   now uses the moving group's member count. Opposite global selector values,
   occupied siblings, same-host occupancy, refusal immutability and undo are tested.
2. A physically FIT 901-part document needed 4,101 mesh objects before markers,
   beyond the fixed 4,096 render reservation. The editor now derives reservation
   from admitted document parts N, maximum catalog mesh count M, maximum authored
   placement membership P, plus all connector markers S and one held part:
   **(N + P + 1) × M + S**. Current values: (1024 + 8 + 1) × 17 + 1024 = **18,585**.
   The refused draft can contain N+P parts; a preview replaces the current drawing.
   Reconnect adds none. Flight adds at most 32 jets + main plume + slab, covered by
   the marker allowance. The same capacity reaches managed buffers and native
   preparation. Native uses 64-bit byte arithmetic and the actual device storage
   range, with rejection before allocation/copy. Active-length copying is retained.
