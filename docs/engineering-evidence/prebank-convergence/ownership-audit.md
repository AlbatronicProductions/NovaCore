## Retained fallback conditions

| Fallback / refusal | Trigger and why primary cannot cover it | Authority, lifetime, exit and failure prevented |
|---|---|---|
| Launcher `dotnet run` | Matching configuration's executable is absent | `NovaCoreProcessLauncher`, one launch plan/process; subsequent build enables normal executable. Preserves source development without silently selecting another configuration. Existing Launcher tests protect it. **KEEP**. |
| Cold Earth hierarchy/global representation | Prepared NCSM1 owner has not passed complete readiness | Native verified immutable L0-L2 hierarchy, renderer lifetime; successful validated publication transfers visible ownership. Prevents absent/incomplete Earth while preparation is pending. **KEEP**; no cold/global closure claimed. |
| Published regional pupil retention | Incoming dependencies/generation/preparation incomplete | `RegionalPhysicalResidency.inl` and native publication own old/new pupils until complete replacement. Prevents partial or mismatched physical publication. **KEEP**. |
| Compatible host memory | Preferred type unavailable or allocation/map-capacity failure | `MappedBufferMemory.h` selects a distinct compatible host-visible/coherent type; native buffer owner cleans failed allocation and releases successful memory at teardown. Device/validation errors remain fatal. Primary optional locality cannot cover unavailable capacity. Existing mapped-memory tests cover retry/nonretry/UMA exclusion. **KEEP**. |
| Missing physical data / authority | Verified global/regional publications or manifest identity absent or mismatched | `PlanetaryPhysicalSurfacePointQuery` returns `RequiredDataNotReady` for unloaded data, `AuthorityUnavailable` for a missing manifest and `AuthorityMismatch` for mismatched identity. Prevents fabricated physical authority until verified acquisition. Fail-closed refusals, **KEEP**. |
| Retained TES route | Raster diagnostics, negative uploaded factor probes or otherwise ineligible direct prepared surface | `PreparedSurfaceRaster.h` decides per submission; buffers/pipelines stay with native renderer. Eligible ordinary draws use direct route; other supported conditions keep their actual tessellation semantics. Existing native eligibility and factor tests required. **KEEP**. |
| MinimumRecorder ordinary exception | Storage cannot safely reserve without destroying protected evidence | Existing `OrdinarySession`/`OrdinaryStorage` policy: mandatory qualification refuses; ordinary user launch explicitly reports exception. Separate Project Control disposition remains. **KEEP** required integration. |
