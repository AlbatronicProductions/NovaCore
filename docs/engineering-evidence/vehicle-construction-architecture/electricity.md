# Electrical service candidate

Cold electricity-connected components collect per-part batteries, engine generators, solar generators and ordinary loads. There is no bus voltage, resistance or chemistry solver. Explicit Electricity capability is independent from Data and Propellant. Disabled batteries do not supply or receive energy. Generation deposits into batteries; no battery means no generator-to-load shortcut.

Current installed KSA generation phases are engine generators, then solar generators, then ordinary loads. Within a phase NovaCore uses explicit part order and stable module ID. The battery cursor advances past the battery that finishes a request, even if that battery is not empty/full. Partial one-pass supply resets the cursor to zero. A partially supplied ordinary load remains Active for that interval; starting a later interval without charge disables it until an explicit reactivation command. A light-switch auto-retry module is not currently admitted.

NovaCore adapts energy arithmetic to exact binary64-derived Q-joules. Solar/load rates integrate integer microticks. An engine generator integrates actual rational powered ticks from the jointly calculated fuel interval; installed KSA uses whole dt after its engine CommandBurnTime check, so exact partial-duration generation is an intentional physical-accounting adaptation. Joint denominator checks include power, fuel state and activity fractions under the same cumulative fuel-event bound. Fill/drain allocation introduces no new division. Overflow generation spills; partial load delivery is reported exactly.

The power kernel produces immutable proposed energy, Active and cursor state. It cannot publish canonical state. The qualified Stage6 path derives fuel and power from the same source/interval and installs their joint successor under SimulationTransactionEngine; independently fabricated solver outputs are not authority.

Power snapshots pin network identity and preserve exact charge, denominator, load state, battery cursors and inherited event count. Integer encodings and document size are bounded before parsing. Module admission limit512. Following the historical stop, Project Control authorized one focused arithmetic correction. For D=1+P*r and I=D+2199, H=floor(I/4)+2 and W=4H, the corrected expression magnitude bound is max(2D,W), and minimum signed two's-complement width is max(2D+1,W). The shared runtime derivation includes malformed length-admitted hexadecimal values and checks the accumulated denominator before the next composition. Generation-before-load clipping and battery cursors make power cadence-dependent, as in installed KSA. Deterministic replay promises the same admitted interval sequence, not invariance to arbitrary regrouping of power intervals. Idle power may retain an earlier fuel-event watermark; joint admission requires compatible bounds and lineage, not false equality of that watermark with current fuel events.

DLV electrical hardware has mass ownership but no accepted capacity/generation/load parameters. Its generic static binding contains zero active electrical modules; that is explicitly unqualified hardware, not zero-energy flight-qualified batteries. Nine isolated electrical components and one attached data component are valid graph witnesses, not electrical flight admission.
