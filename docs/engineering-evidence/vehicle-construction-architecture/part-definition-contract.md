# Definition and instance contracts

PartDefinitionData/DefinitionReference/PartInstanceData remain shared owners. The optional Construction extension uses composable capabilities for generic Component definitions; legacy roles remain SRV admission metadata. Nullable extension omission preserves banked schema bytes. The existing SRV compiler and generic construction use the same placement/dependency/tensor transform helper.

Catalog schema novacore.construction-catalog/1 is immutable after validated compilation. Logical definition ID, integer revision, canonical definition digest and independent visual content SHA256 are distinct. Multiple revisions coexist; missing or changed references fail. Development=true marks current content, never controls runtime behavior. Collections are immutable and membership ordering is canonical, including nested mixture/feed/subpart bindings.

PhysicalSource pins constituent provenance. Mass regions derive and verify dry aggregate mass, COM and full inertia. Explicit stores bind capacity, datum, usable loaded-region volume and full-load specific tensor. Resource names are data. These static construction witnesses do not qualify a changing tank fill geometry or launch-scale motion law. A future dynamics profile must admit those laws explicitly.

Runtime observation identity is vessel plus lifetime generation, then design-local part ID; subpart identity adds stable parent-local ID. Identity values alone do not grant a publication capability. Actual runtime issuance/retirement is qualified in Stage 6, not by a catalog load.
