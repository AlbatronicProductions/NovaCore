separately in three fresh Release processes. Retain existing complete-operation
campaign:128 warm then1024 measured on a1200-interval episode. Operation includes
host admission, step, export, final checks, atomic publication, acknowledgement

## Payoff/stop decision

This unlocks real canonical production assembly support using retained contact,
without replacing parts/resources with a qualification body. It enables later
powered support/departure/surface discussions but authorizes none. Stop if faithful
collision authoring demands a new collision engine, arbitrary craft framework,
new resource/mass law, terrain or banked free-flight changes. Quantitative payoff
and physical/performance acceptance remain to be demonstrated by implementation.
