## Independent final red team: additional stopped-candidate findings

These are unresolved findings, not corrections made after the performance stop:

1. The new physical test has no independent native-thrust/support-load witness. Current source supplies nonzero thrust, but a defect omitting it while continuing to debit resources could pass the current assertions. The defining powered-support outcome is not fully protected yet.
2. `supported++` counts final iterations admitted by production, rather than independently reapplying Stage 1's final-height predicate. Settled linear/angular-speed bars are also absent from the new test. Therefore its printed 600 count is not an independently qualified 600/600 support result. The measured penetration/drift values remain valid; full physical qualification is incomplete.
3. `Step` has an explicit prepared-frontier guard for the older powered path but not the new assembly input. `RefreshAssemblyMass` checks an owner phase without independently checking that the supplied engine owns this world/source. The present transaction calls them correctly; helper boundaries do not fully enforce that order and identity themselves.
4. Native `Export.Motion` still carries initial assembly mass/inertia after depletion. Canonical publication extracts only its kinematics and separately installs the correct exact-store-derived successor mass, so current canonical values are not corrupted; the native export's typed properties are stale.

Red-team judgment: Stage 2 UNQUALIFIED. No additional source/test correction was made after the stop. Project Control receives these findings together with the performance blocker.
