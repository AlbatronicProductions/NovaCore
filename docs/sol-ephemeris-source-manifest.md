# SolEphemeris source manifest

The planned dataset is `SolEphemeris-DE440-2000-2050`, in an opaque TDB/ET-compatible domain anchored at J2000 ET, with one million domain ticks per second and a 1:1 simulation-time mapping.

Its target map has an explicit SSB root, Sun, Mercury and Venus barycenters, EMB, Earth, Moon, and Mars through Neptune barycenters. Earth and Moon are explicit EMB children. This source hierarchy does not constrain a future Earth-centered observation frame.

This milestone contains only a template manifest plus synthetic verification. Its placeholder hashes are intentionally non-authoritative and cannot produce an authoritative dataset. It contains no kernel, official verified hash, physical-constant extraction, source vector, or real NCPE artifact.
